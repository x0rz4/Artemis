# 基线工具安装

## 范围

为 Artemis 离线工具库下载固定工具、验证资产并生成运行时清单。实现入口是 `scripts/install_tools.py`、`packaging/tools-lock.json` 和 `install.sh --tools`，使用说明见 [基线工具安装](../../../packaging/README.md)。后端工具执行与数据库注册维持 [项目约束](../../PROJECT.md)。

## BT-001 固定来源与严格校验

每项工具必须具有固定版本、平台、HTTPS 资产地址和非空 SHA-256。下载先验证归档摘要，再提取指定普通文件；清单记录提取后文件的摘要。脚本不得执行下载内容。归档穿越、链接、重复路径、大小超限、摘要或 ELF 架构错误必须失败。

基线为 httpx、naabu、subfinder、katana、ffuf、nuclei、fscan、kscan。Linux amd64 支持八项；Linux arm64 支持除 kscan 外七项。所选工具缺少平台资产时必须提前失败，不静默跳过。

- GIVEN：有效下载锁与所选平台；WHEN：安装；THEN：生成匹配平台的文件与 Artemis 清单，摘要对应实际文件。
- GIVEN：不受支持的平台或资产校验失败；WHEN：安装；THEN：非零退出，原有清单与文件不变。

## BT-002 保留已有工具与平台配置

安装必须按名称合并清单，保留未选择的条目、sources、未知元数据及已有 key、agents、enabled、deferred、schema。新条目默认禁用；导入与 Agent 绑定由用户在平台完成。相同版本且文件完整时不得重复下载、改写清单或产生快照。

工具按下载摘要和文件摘要分目录存储，不覆盖原工具文件；先落盘新文件，再原子切换清单。失败可以留下未被引用的新目录，不得让清单引用未验证的文件。

- GIVEN：带本地工具和定制绑定的清单；WHEN：更新所选工具；THEN：保留其它条目与绑定，旧版本文件仍可访问。
- GIVEN：同版本完整安装；WHEN：重复执行；THEN：不发生下载，清单字节保持不变。

## BT-003 安装流程与恢复

`install.sh --tools baseline` 或逗号分隔的工具名列表启用下载；默认安装不额外下载工具。Docker 模式使用 daemon 平台，本地模式使用宿主平台。启用该选项需要宿主 Python 3.8+。`--no-start` 准备工具但不启动应用或数据库；下载失败必须返回非零状态。

安装要求 Artemis 停止使用该库。Compose 入口检测运行中的应用并拒绝写入，直接运行 Python 脚本时由操作者先停止服务。独占安装锁仅防止多个脚本同时写入；提交前必须再次检查旧清单是否发生变化。

切换已有清单前创建 `manifest.json.bak` 和工具库兼容快照，最多保留五份。因为旧二进制不被覆盖，安装快照仅需包含旧清单；恢复清单后复用原文件，随后重新导入。脚本不得操作业务数据库或自动创建扫描任务。

- GIVEN：准备模式；WHEN：运行带 `--tools` 的安装；THEN：工具和清单就绪，服务不启动。
- GIVEN：应用或另一安装脚本仍在使用工具库；WHEN：通过相应检查入口安装；THEN：拒绝写入并提示处理方法。
- GIVEN：更新后的库与更新前快照；WHEN：恢复旧清单；THEN：旧路径所引用的工具文件仍存在，不删除更新后的其它文件。
