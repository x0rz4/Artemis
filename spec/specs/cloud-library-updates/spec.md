# 工具库与 Skill 云更新

## 范围

官方工具与 Skill 的独立发布、检查、选择安装、冲突处理和回滚。部署与 API 说明见 [云更新](../../../packaging/REGISTRY.md)，架构约束见 [PROJECT](../../PROJECT.md)。

## CLU-001 独立且固定的发布源

官方源为公开 `x0rz4/Artemis-registry`。源码保存版本、上游 URL、SHA-256、平台、许可证与 Skill 文件；二进制、Skill ZIP 及清单使用版本化 Releases。首批 amd64 八个工具、arm64 七个工具（不含 kscan）和三个 Skill。所有资产校验与两种原生架构的帮助/版本检查通过，上传后重新下载验证，才公开 Release 并更新稳定索引。已存在版本不得覆盖；客户端不得跟踪上游 latest。

- GIVEN 固定锁文件；WHEN 发布；THEN ZIP、内容摘要、两类清单和许可证完整，kscan 同时提供对应版本源码归档。
- GIVEN 任一资产或运行检查失败；WHEN CI 结束；THEN 不推进稳定索引。

## CLU-002 只读自动检查

启动后后台检查一次，此后每六小时检查。可关闭自动检查、立即检查；设置和已验证清单持久化在 `data/registry-state.json`。检查仅读取稳定索引和两类清单，必须校验清单摘要，不下载工具包，不自动安装。

- GIVEN 已安装内容；WHEN 网络中断或清单摘要错误；THEN 显示检查错误，保留已知版本及当前内容。
- GIVEN 关闭自动检查；WHEN 保存并重启；THEN 设置保持关闭，立即检查仍可使用。

## CLU-003 选择条目与固定版本

沿用 `/api/tool-lib/sync`、`/api/skills/sync`，`names` 保持源名称语义；官方请求单独指定 `artemis-registry`，`items` 指条目，`release` 必须是本实例检查过的版本。`replace` 是逐项替换冲突授权。检查过的同一发布版本不得接受不同清单摘要。现有自定义源与离线脚本保持可用。

- GIVEN 检查 release A 后稳定渠道推进 B；WHEN 按 A 确认；THEN 只使用 A 的固定清单与包摘要。
- GIVEN 请求未检查的 release 或不存在条目；WHEN 同步；THEN 拒绝，不安装任何包。

## CLU-004 版本与内容判定

页面显示本地版本、云端版本、变更、平台支持、冲突和检查错误。元数据分别记录包 SHA-256 与内容 SHA-256；工具原 `sha256` 为入口文件摘要。内容摘要使用排序后的相对路径和文件摘要，与 ZIP 时间戳、权限无关。

- GIVEN 已安装相同版本且内容未变；WHEN 再检查或应用；THEN 显示已是最新，不重复下载或安装。
- GIVEN 内容被修改、缺失或平台不支持；WHEN 检查；THEN 明确显示冲突或不支持。

## CLU-005 保留工具平台状态

更新保留本地 key 和数据库中的 Agent 绑定、启用与 deferred，新工具默认禁用。工具注册按批事务执行，注册或清单发布失败必须恢复原定义与清单。

- GIVEN 用户已在工具管理中调整绑定和启用；WHEN 云端更新；THEN 定义刷新，平台状态保持。
- GIVEN 同批注册失败；WHEN 返回错误；THEN 旧清单和原工具仍可使用。

## CLU-006 Skill 生效与冲突

官方 Skill 位于独立持久化 `data/skills/managed/`，由清单选择生效版本。优先级为显式本地配置根、已激活官方版本、内置、上传、git。每轮 Agent 装配动态解析根。内置副本保留，回滚清单可恢复内置回退。同名自定义内容和检测到的本地修改默认跳过；只有 `replace` 中的条目允许替换。显式本地根仍优先，页面提示覆盖。

- GIVEN 官方更新成功；WHEN 下一轮调用 Skill；THEN 实际返回新内容，无需重启。
- GIVEN 同名自定义 Skill；WHEN 未明确选择替换；THEN 不下载、不覆盖；确认后保留旧内容及快照。
- GIVEN 更新后回滚；WHEN 调用 Skill；THEN 返回原版本或内置内容，残留新目录不会继续生效。

## CLU-007 空闲应用、互斥和恢复

下载可后台进行；应用和回滚必须任务、聊天空闲，库写操作互斥。任务/聊天准入与切换使用同一门禁，忙碌返回 409。更新先快照，下载、ZIP 路径、包摘要、内容摘要、ELF 平台或 Skill 解析验证完成后才切换清单。失败不得覆盖当前版本，允许保留未引用的新目录。

新快照包含文件摘要。回滚先暂存和校验，再切换文件，清单最后生效；工具注册失败恢复回滚前快照。最多保留五份，不能清理本次选中的回滚目标。快照按条目恢复；未涉及条目和云端已删除条目不得自动删除本地文件。

- GIVEN 错误摘要、断网、非法 ZIP 或错误架构；WHEN 更新；THEN 旧版不变。
- GIVEN 任务/聊天忙碌或并发写入；WHEN 应用；THEN 返回 409，切换不发生。
- GIVEN 损坏或缺失内容的快照；WHEN 回滚；THEN 在切换前失败，当前内容不变。
